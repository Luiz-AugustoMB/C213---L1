# C213 - Lista 1

Resoluções das listas de exercícios de MATLAB/Octave da disciplina C213.

## Estrutura

```
07-08-2026/
├── Lista01.m          # Operações aritméticas, vetores e matrizes
├── Lista02.m          # Entrada de dados, condicionais, laços e funções
└── funcao_triplo.m    # Função auxiliar usada na Lista02
```

## Como executar

Abra os arquivos `.m` no MATLAB (ou GNU Octave) com a pasta `07-08-2026/`
definida como diretório de trabalho e execute seção por seção (`%%`).

> `Lista02.m` usa `input()` no Exercício 01, então requer execução interativa.
